Command Line Interface
======================

Installing the package puts a ``scraper`` command on your ``PATH``. The same
parser is reachable three ways, all equivalent:

.. code-block:: bash

   scraper --url <URL> --patterns .csv .zip --dir data --max-files 10
   python -m scraper_lib --url <URL> --patterns .csv .zip --dir data --max-files 10
   python -m scraper_lib.cli --url <URL> --patterns .csv .zip --dir data --max-files 10

Examples
--------

Download every CSV published on a page:

.. code-block:: bash

   scraper --url https://data.example.com --patterns .csv

Limit the run to 10 files and put them in ``data/``:

.. code-block:: bash

   scraper --url https://data.example.com --patterns .csv --dir data --max-files 10

Resume an interrupted run -- ``--incremental`` reads the state file and skips
what is already on disk:

.. code-block:: bash

   scraper --url https://data.example.com --patterns .csv .zip \
       --dir data --incremental --state-file state/download_state.json

Run 16 downloads in parallel with 10 MB chunks and quiet the progress bar, which
is what you want inside a scheduled pipeline:

.. code-block:: bash

   scraper --url https://data.example.com --patterns .parquet \
       --dir data --max-concurrent 16 --chunk-size 10mb \
       --disable-progress-bar --disable-terminal-logging
